# Texture sources

The forest floor and pine bark textures in this folder are derived from Poly Haven's 1K JPEG colour and OpenGL normal maps. They have been resized to 512 × 512 pixels and recompressed for the browser.

- [Forest Ground 01](https://polyhaven.com/a/forrest_ground_01) by Rob Tuytel — `ground.jpg` and `ground-normal.jpg`.
- [Pine Bark](https://polyhaven.com/a/pine_bark) by Dimitrios Savva — `bark.jpg` and `bark-normal.jpg`.

Both assets are released under the [Poly Haven CC0 licence](https://polyhaven.com/license).

The tree foliage uses 1K diffuse and alpha atlases resized to 512 × 512. The application selects one isolated leaf or pine sprig from each atlas:

- [Island Tree 01](https://polyhaven.com/a/island_tree_01) by Rob Tuytel and Rico Cilliers — `leaves.jpg` and `leaves-alpha.png`.
- [Pine Tree 01](https://polyhaven.com/a/pine_tree_01) by Rob Tuytel and Rico Cilliers — `needles.jpg` and `needles-alpha.png`.

These assets are also CC0.
